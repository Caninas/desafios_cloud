1 - Camada 2: Ela é chamada de camada de enlace. É a camada que define a forma como ocorre a comunicação entre dispositivos em uma rede local. Ela é encarregada de transmitir os chamados quadros entre dispositivos da rede local. Exemplos de protocolos utilizados nesta camada são o Ethernet e Wifi, organizando os bits da camada física em quadros e adicionando endereços MAC. A forma de endereçamento dessa camada é realizada através do endereço MAC do dispositivo guardado no quadro/frame. O endereço MAC é um endereço físico único para cada dispositivo já produzido no mundo. Algumas exceções podem existir já que existe um número máximo de endereços MAC possíveis.

Camada 3: Ela é chamada de camada de rede e é parecida com a camada 2, mas em vez de se encarregar da transferência de dados entre dispositivos em uma rede local, ela se encarrega de transferir/rotear dados entre dispositivos em diferentes redes dentro da internet, sem garantia de entrega. Novos cabeçalhos são criados para realizar o roteamento, com informações como endereço de origem, destino, versões do protocolo, checksum etc., resultando no chamado pacote IP. O protocolo de endereçamento dessa camada é o IP (v4 ou v6). Ele é um tipo de endereçamento lógico, podendo mudar dependendo da rede onde o dispositivo está conectado. Um endereço IP privado é reutilizável entre diferentes redes, enquanto o público é "único".


2 - O Windows, por ter uma adoção maior do mercado, costuma possuir maior compatibilidade de aplicativos e hardware quando comparado ao Ubuntu. Além disso, por ter uma empresa grande por trás, costuma trazer mais suporte e features empresariais. Alguns pontos negativos do Windows são o custo de licenciamento, dependência da Microsoft para atualizações e maior utilização do hardware pelo sistema. Um sistema operacional open source como o Ubuntu, apesar de ter uma curva de aprendizado maior, é gratuito, costuma consumir menos recursos que o Windows e é open source, permitindo que o seu código-fonte seja analisado e modificado, fazendo com que a comunidade possa contribuir para o desenvolvimento de features do sistema ou criar versões próprias para casos de uso específico. Os sistemas operacionais Linux são bastante utilizados em ambientes de servidores, onde quanto menor o overhead do sistema operacional, melhor.


3 - É um projeto onde o código fonte é publicamente disponibilizado. Um software sob uma licença de código aberto permite que o código seja visto, modificado e, dependendo da licença, distribuído por outras pessoas e empresas além do criador. Uma empresa pode adotar projetos open source em diversas áreas. Desde softwares tradicionais (como o LibreOffice), bibliotecas/frameworks em linguagens de programação até sistemas operacionais como as distribuições do Linux. As principais vantagens dos softwares open source são a redução ou ausência de custos de licenciamento e possibilidade de modificar o produto de acordo com as necessidades específicas da empresa. Apesar disso, alguns pontos negativos devem ser levados em consideração. Por exemplo, vulnerabilidades de segurança ou problemas de compatibilidade podem surgir, o que acarreta a necessidade de a empresa gerenciar com cuidado as atualizações de dependências de um projeto.
